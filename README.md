# Conscious Compute

The ConsciousCompute.org working paper, built with Next.js 16 and Tailwind CSS v4, deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build (every route should be static)
npm run lint
```

Rules for anyone (or any AI tool) working on this repo: [AGENTS.md](AGENTS.md).
