# SEO: Content vs Technical

> Copy/positioning SEO changes need approval; technical SEO fixes don't; verify audit claims first

Conscious Compute rule: titles and descriptions are deliberate choices by the owner, so don't change them just because an SEO audit says so. Audit findings are often wrong when checked directly.

**How to apply:** Ask before changing titles, descriptions, keywords or positioning copy. Technical fixes (canonical, sitemap, structured data, heading order, contrast, dead links) are fine to fix directly. Verify any "X is missing/broken" claim yourself (curl the page, read the code) before acting. On this site, the `noindex` setting is deliberate while the paper is a draft.
